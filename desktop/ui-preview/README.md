# ChatGPT Studio 可读性重设计预览

当前迭代调整 App 自有 UI 的字号、对比度、操作层次和窄窗口布局，沿用白灰黑、无地址栏与账号色点。alpha.17 已有真实资产工作台 / Skill 功能；本目录的新可读性样式尚未迁入安装包，应用版本没有因此升级。辅助账号、诊断、更新与菜单栏窗口均明确是布局示例。

## 打开

在仓库根目录执行（只提供本目录明确允许的静态文件）：

```sh
node desktop/ui-preview/serve.mjs
```

访问 <http://127.0.0.1:4188/>。可比较原版 / 调整后 / 大字号，使用实际预览的资产与 Skill 交互；顶部可查看账号、七阶段任务、设置诊断、更新和 Mac 菜单栏样式。窄窗口以详情抽屉代替缩小文字。预览不依赖前端构建和外部服务。

正文以 15px 为主、辅助文字 14px、元数据标签至少 13px，正常文字采用深色对比；文档缩略图中的缩小内容不属于 App 控件文字。可用状态不会伪装成灰掉的不可用入口；禁用状态保留可读文字并说明原因。`readability-typography.css` 是预览专用的原有文字角色迁移层，微型文档内容明确排除；正式接入会按真实组件职责调整。

## 本轮可以操作

- 顶部资产/能力库入口、账号切换和返回网页示意。
- 按账号筛选文件、搜索来源与标签、网格/列表、排序、收藏、批量选择、重命名、标签和回收站恢复。
- 图片、HTML 网页/源码、文本/数据查看；PDF 只演示分页布局。
- 主动选择或拖入文件后，在当前页查看。导入归属固定为发起操作时的账号；不扫描本机目录，不写入原文件，页面关闭后不保留导入数据。
- 格式转换流程演示：添加明确标记的副本示意，并展示与原件的关系。没有生成真实转换文件。
- 选择 Skill、可选专业角色、目标账号和处理要求；跨账号时需明确确认。执行界面为演示，不会创建 ChatGPT 对话、上传文件或发送消息。

示例文件名称、大小、尺寸、下载时间和来源对话均为预览数据；缩略图为本目录 SVG 示意，不是那些格式的实际二进制文件。两个账号及邮箱均为示例备注。

HTML 预览使用不带权限的 `sandbox` iframe，并限制脚本、网络、表单与外部文件访问；上层预览也通过 CSP 限制外部请求。这只证明当前浏览器预览的行为，原生模块仍需单独实现与验收。

## 能力目录

预览包含 120 个本项目任务草案，智能体列表当前为空；空列表用于检查统一组件的空状态。这是可读性预览目录，不能用它判断安装版的目录数量或任务执行结果。

## 本轮验证

本轮实际渲染检查了 1440×1000、1280×900、900×760 的代表性布局，以及原版 / 调整后 / 大字号切换。资产属性行与底部四个操作按钮保持 14px；窄窗口抽屉和大字号检查没有横向溢出，操作区仍可见。账号输入为 15px、标签 14px，Skill 说明为 15px；诊断和更新示例的正文、禁用说明可读。七阶段进度为模拟流转，已检查完成状态与可见的弹窗底部按钮。

截图位于 `docs/images/readability-*-proposal.jpg`，只包含合成示例。真实 App 的原生菜单栏与后续字体迁入在 GitHub Actions 单独验证，预览不替代安装包或真实 ChatGPT 的验收。
