# macOS 资产工作台交互预览

当前迭代为 UI 预览，沿用白灰黑、无地址栏与按账号区分的设计。实际客户端源码和已发布安装包尚未接入这些功能，应用版本没有因此升级。

## 打开

直接用浏览器打开 `index.html`；或在仓库根目录执行：

```sh
python3 -m http.server 4186 --bind 127.0.0.1 --directory desktop/ui-preview
```

访问 <http://127.0.0.1:4186/>。可用 `#assets`、`#skills`、`#agents`、`#chat` 直接进入不同界面。预览不依赖前端构建和外部服务。

## 本轮可以操作

- 顶部资产/能力库入口、账号切换和返回网页示意。
- 按账号筛选文件、搜索来源与标签、网格/列表、排序、收藏、批量选择、重命名、标签和回收站恢复。
- 图片、HTML 网页/源码、文本/数据查看；PDF 只演示分页布局。
- 主动选择或拖入文件后，在当前页查看。导入归属固定为发起操作时的账号；不扫描本机目录，不写入原文件，页面关闭后不保留导入数据。
- 格式转换流程演示：添加明确标记的副本示意，并展示与原件的关系。没有生成真实转换文件。
- 搜索 120 个不同任务 Skill 的目录与流程草案，以及 328 个智能体摘要。互联网候选 232 个在前，其他 96 个完整保留。
- 选择 Skill、可选专业角色、目标账号和处理要求；跨账号时需明确确认。执行界面为演示，不会创建 ChatGPT 对话、上传文件或发送消息。

示例文件名称、大小、尺寸、下载时间和来源对话均为预览数据；缩略图为本目录 SVG 示意，不是那些格式的实际二进制文件。两个账号及邮箱均为示例备注。

HTML 预览使用不带权限的 `sandbox` iframe，并限制脚本、网络、表单与外部文件访问；上层预览也通过 CSP 限制外部请求。这只证明当前浏览器预览的行为，原生模块仍需单独实现与验收。

## 目录来源与许可

- `catalog.js`：120 个本项目任务草案；328 个上游角色的名称、摘要、分类与源文件链接。
- 此预览没有运行上游安装脚本，没有安装或修改全局 Codex skills。角色摘要的导入不等于其终端、MCP、部署等执行工具已接入。

## 本轮验证

真实 Chromium 检查了 1440×1000、1280×900、900×760：无横向溢出；资产整理、账号归属、回收站恢复、HTML 沙箱/源码、派生关系演示、两库的数量/搜索/排序、跨账号确认与目标身份、主动文件导入、返回网页及离线文件入口通过。测试期间没有页面脚本错误或外部网络请求。

实际渲染截图位于仓库 `docs/images/macos-assets-ui-preview.png`、`macos-agents-ui-preview.png`、`macos-send-ui-preview.png`。这些是浏览器中的 UI 预览截图，不能作为原生功能或真实 ChatGPT 业务验收证据。
