03 / QUICK START

三步，进入状态。

完整使用文档
01—

安装，然后打开

下载对应平台的安装包。Mac 将 App 拖入“应用程序”；Windows 运行 EXE 或解压 ZIP；Android 按系统提示安装 APK。

02—

创建空间，登录账号

打开即进入 ChatGPT。在网页中手动登录，再从右上角账号菜单添加其他空间，为每个空间写好名称与邮箱备注。

切换账号，继续思考

从账号菜单切换空间，用标签组织不同对话。账号名称与邮箱均为手动备注，请在网页内核对实际登录身份。

反馈问题
这是 OpenAI 官方应用吗？+

不是。ChatGPT Studio 是独立维护的非官方网页客户端。ChatGPT 服务和订阅由 OpenAI 提供，本项目不附带订阅，也不需要 OpenAI API Key。

账号隔离具体意味着什么？+

不同空间使用独立 Cookie、网页存储与登录会话，同一空间内的标签和登录弹窗共享会话。应用不收集密码，也不将 Cookie 上传至自建服务。隔离不会改变 IP 或伪装设备指纹，也不保证所有第三方登录渠道可用。

Mac 或 Windows 提示无法打开，怎么办？+

Mac 构建采用 ad-hoc 签名，未经过 Developer ID 签名与 Apple 公证；确认下载来源和文件摘要后，可按 Apple 官方指引处理。Windows 构建未经过 Authenticode 签名，可能触发未知发布者或 SmartScreen 提醒。请确认文件来自本仓库 Release，按设备的安全策略决定是否运行。

账号会同步到其他设备吗？+

不会。每台设备各自登录、各自保存账号与标签，没有跨设备同步服务。ChatGPT 本身的云端对话遵循其服务规则。macOS 账号数据在“~/Library/Application Support/ChatGPT Profiles/”；Windows 安装版和 ZIP 均在“%APPDATA%\ChatGPT Profiles\”；Android 在应用私有目录。

Android 为什么提示更新 WebView？+

独立账号依赖系统 WebView 的多档案能力，Android 版本达标并不代表 WebView 已支持。请更新 Android System WebView / Chrome 后重试；不支持时应用会阻止使用，避免退回共享账号空间。当前暂不支持 blob: 文件下载。

Android 如何让任务在后台继续？+

从底部“更多 → 保活与诊断”主动开启后台任务模式，允许通知后会显示常驻通知，可随时停止。App 前台保持已打开标签执行；后台模式会增加耗电，系统休眠、厂商省电、强制停止与网络服务仍可能中断任务。诊断入口可查看版本、网络和重载记录，应用不会自动重发结果不明的消息。

如何校验下载、更新或清除账号？+

下载卡片中可复制 SHA-256；Windows 使用 PowerShell 的 Get-FileHash，Mac 使用 shasum -a 256，对照结果。macOS alpha.12 支持确认后后台更新与可选应用空闲安装；alpha.11 及更早版本需先手动安装一次。Windows / Android 继续手动更新，Android 需要保持相同签名。手动升级前请从应用菜单真正退出旧版，再覆盖安装，无需卸载或清理账号数据。账号菜单可清除本机登录或移除空间，这不会删除 ChatGPT 云端对话。Windows 卸载默认保留账号数据，Android 卸载会删除本机空间。
