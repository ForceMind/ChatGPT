# Android 最小差异评审预览

本目录是基于已发布 alpha.18 的局部调整评审稿。alpha.18 的沉浸布局已经接入原生 App；本轮只统一标签文案，账号、标签入口、更多和列表布局沿用。用户确认后，这组文案已接入 alpha.19 候选源码，原生 CI 与安装包验证按开发记录追踪。

默认用留白标示“ChatGPT 网页保持原样”，避免把模拟首页误认为网页改版。需要查看交互背景时，可在设备外的评审工具开启“显示网页示意”；其中的首页、消息和输入框是合成示例。留白和评审工具都不进入正式 App。

在仓库根目录运行：

~~~sh
node android/ui-preview/serve.mjs
~~~

打开 http://127.0.0.1:4187/ 。服务只监听本机，静态白名单不提供账号、签名材料或其他仓库文件。

## 本轮最小差异

- 顶部“对话 N”改为“标签 N”，弹层“打开的对话”改为“标签页”。
- 搜索、新建、关闭和管理统一使用“标签页”，与 ChatGPT 网页里的云端对话区分。
- 设备内的布局、账号和工具入口保持现有位置。标签管理仍使用手机底部弹层或平板侧边面板。
- 标签列表继续显示标题和所属账号，保留搜索、账号筛选、切换、固定、重命名、关闭、撤销与最近关闭。
- 最近关闭使用文字入口；主页不放无历史时无动作的后退按钮。
- 菜单保留新开对话、资产库、能力库、处理记录和账号管理；本机草稿位于账号管理。没有面向普通用户的保活 / 引擎 / 诊断菜单。
- 文件按示例账号归属展示；保留预览、格式选择与交给 GPT 的布局。跨账号处理文件需要明确确认。
- 任务展示七步进度与处理记录。所有任务与格式流程均为模拟，没有真实上传、转换、发送或文件写入。
- 开启网页示意后，输入区和标签切换复用本页示例状态，展示草稿不重置的交互。它不证明 Android WebView 或真实 ChatGPT 的保留能力。

本轮只需检查默认网页标示、新标签文案、搜索 / 关闭 / 恢复和原菜单入口，以及手机、小屏大字号、平板的实际渲染。之前的整体原型图片保留在 docs/images/android-immersive-proposal-*.jpg，属于历史合成示例，不代表本轮扩大了改动范围。

## 范围与验证边界

用户在 alpha.18 发布后要求遵循最小设计、沿用现有体验；涉及布局或操作路径的变化先提供最小差异。用户已确认本轮预览并要求继续；当前交付为 Android alpha.19 候选，公开安装包和官网仍保持 alpha.18。

alpha.18 的原生切换保留、附件和字号检查见 docs/releases/3.0.0-alpha.18-ci.json（相对仓库根目录）。本预览的模拟交互不替代这些原生证据，也不代表真实 ChatGPT 验收。

范围、批准、CI、候选与剩余工作统一记录在根目录 MACOS_MIGRATION_PLAN.md。
