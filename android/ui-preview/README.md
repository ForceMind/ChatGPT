# Android 沉浸式交互设计预览

本目录是 ChatGPT Studio 自有 Android UI 的设计评审稿。主页面保留账号、打开的对话和更多入口，没有地址栏和常驻底部导航；网页区域是本地示意。尚未迁入原生 App，不是安装版截图或真实服务验收。

在仓库根目录运行：

~~~sh
node android/ui-preview/serve.mjs
~~~

打开 http://127.0.0.1:4187/ 。服务只监听本机，静态白名单不提供账号、签名材料或其他仓库文件。

## 设计与交互

- 默认进入网页；对话管理按需以手机底部弹层或平板侧边面板打开。
- 对话清单显示标题和所属账号，保留搜索、账号筛选、切换、固定、重命名、关闭、撤销与最近关闭。
- 最近关闭使用文字入口；主页不放无历史时无动作的后退按钮。
- 菜单保留新开对话、资产库、能力库、处理记录和账号管理；本机草稿位于账号管理。没有面向普通用户的保活 / 引擎 / 诊断菜单。
- 文件按示例账号归属展示；保留预览、格式选择与交给 GPT 的布局。跨账号处理文件需要明确确认。
- 任务展示七步进度与处理记录。所有任务与格式流程均为模拟，没有真实上传、转换、发送或文件写入。
- 输入区、对话和账号切换复用本页示例状态，展示草稿不重置的交互。它不证明 Android WebView 或真实 ChatGPT 的保留能力。

已实际操作：输入草稿后跨对话 / 账号切换、关闭撤销、账号文件归属、跨账号确认与七步流程；已检查 390 手机、360 小屏 2 倍 App 字号和 768 平板布局，无横向溢出，操作按钮保留。图示文件位于 docs/images/android-immersive-proposal-*.jpg，均为本项目合成示例。

## 接入前置条件

用户已批准 Mac 的 4188 字号方案，同时要求 Android 的整体交互先重做设计。此稿需要单独确认后再替换原生界面。原生验收必须以 App 仍运行且在前台时，切换已打开页面不增加主文档加载、对象 / 草稿 / 滚动与生成上下文保持为准，不依赖后台服务开关，不用预览模拟成绩替代原生证据。

范围、批准、CI、候选与剩余工作统一记录在根目录 MACOS_MIGRATION_PLAN.md。
