# ChatGPT Studio Beta.4

这是使用固定测试签名的独立Android候选，版本3.0.0-alpha.24-beta.4，名称ChatGPT Studio Beta。Android9+、arm64。

已有固定Beta的用户直接打开APK覆盖安装，不卸载、不清数据。它与正式版和临时签名测试版使用不同包名，不迁移彼此的登录、资产或线路配置。

## 本次功能

在“更多 → 网络”查看实时准备、保存、连接和失败状态。添加、长按编辑或删除线路后，原面板即时更新；失败时在原面板查看原因并重连。线路被选中并不表示已经连接。网络变化仍保留原网页和草稿。

支持VLESS RAW/TCP、TLS和REALITY。请自行配置节点，不提供免费节点。变更线路前会提示正在生成或上传的请求可能中断。

## 校验与边界

安装前核对SHA256SUMS.txt。人用APK不含合成节点、测试程序或测试信任材料。

Android9/15原生控件、线路增删改、实时失败/重试、窗口重建与关闭清理已在GitHub Actions合成环境通过。Android15以已交付Beta.3原始arm64包为升级基线；Android9使用此前已构建的x86 CI输入，不等同于ARM手机验收。本批未访问真实ChatGPT或真实节点，没有截图；真实登录、节点和手机体验仍需实际验收。

验收JSON随包附带。源码和详细说明见仓库docs/android-network-panel.md。本候选不自动更新正式版或个人设备。
