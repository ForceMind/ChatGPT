# ChatGPT Studio · Windows alpha.24

本次仅更新 Windows x64，macOS 继续 alpha.23，Android 继续 alpha.22。

- 新装默认目录、主程序和卸载程序统一使用 ChatGPT Studio。
- 经过身份与文件校验的旧默认程序目录安全迁移到 Studio；自定义安装目录保留原位置。
- 同步更新桌面、开始菜单和已有快捷方式目标，更新器兼容旧、新程序名。

安装包未做 Windows 代码签名，可能出现 SmartScreen 或未知发布者提示。请核对 `SHA256SUMS.windows.txt`。
