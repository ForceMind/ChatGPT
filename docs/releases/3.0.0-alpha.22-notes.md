# ChatGPT Studio 3.0.0-alpha.22

本次更新 macOS Apple Silicon 与 Android。Windows 继续使用 alpha.21，可从官网选择对应平台下载。

## macOS

- 完善右上角账号菜单的淡遮罩及网页绘制交接，减少展开、关闭菜单时的闪烁。
- 当前标签增加强制刷新入口，网页卡住时可以手动重新加载。
- 保留原账号空间、登录数据、加密恢复身份及确认后后台下载、退出或应用空闲时安装的流程。

## Android

- 加密保存对话文字与最近画面；断网重开时可只读查看保存内容，联网后恢复草稿与阅读位置。
- 能力库对齐 121 个 Skill、32 个自有角色，其中 24 个互联网相关角色优先；支持角色单用与组合附件任务。
- 完善账号绑定、任务恢复与输入就绪判断，避免输入尚未准备好时提前提交。
- 沿用原包名和签名证书，可直接覆盖旧版，无需卸载。内核仍为 Android System WebView，需具备多档案能力；独立 Gecko 实验未接入此 APK。

## 下载与升级

- Mac 手动安装请选择 `ChatGPT-Studio-…-mac-arm64.dmg` 或同名 ZIP。
- `ChatGPT-Profiles-…-mac-arm64.zip` 专供旧版自动更新兼容，程序内仍显示 ChatGPT Studio。
- Android 请选择 `ChatGPT-Studio-…-android.apk`，保持相同签名并覆盖安装。
- 手动替换 Mac 前请真正退出 App。安装与更新不会主动清理账号数据；升级前建议保留备份。
- 官网提供原始链接和可选国内加速入口。安装前可对照本 Release 的 `SHA256SUMS.txt`。

## 验证范围

安装包复用原 GitHub Actions 产物，没有重新构建。Mac 已完成单元、隔离界面、完整包内容、签名与两种 ZIP 的升级校验；Android 已完成构建、单元、Lint、手机和平板的合成离线、能力库、字号及进程重启检查。发布前再次核对原始包摘要、原证书与签名前后全部应用文件一致。

macOS 仍为临时签名、未公证，升级后可能需要重新授权钥匙串；稳定 Developer ID 与 Touch ID 受保护密钥尚未启用。完整 Mac 更新需要重启，暂不支持增量更新；Android 当前手动更新。真实 ChatGPT 附件发送、Android 个人设备升级和厂商后台限制仍需分别验收。

This prerelease updates macOS Apple Silicon and Android; Windows remains on alpha.21. Mac improves account-menu rendering and adds active-tab force refresh. Android adds encrypted offline text/image snapshots and the 121-Skill / 32-role library, using the existing package identity and signing certificate. Existing CI-built binaries are promoted unchanged. The experimental Gecko engine is not included. macOS remains ad-hoc signed and unnotarized; full updates require restart. Android updates manually. Physical-device and live ChatGPT acceptance remain pending.
