# Android 独立账号环境迁入客户端

当前交付目标是可安装的固定签名Beta.5客户端：旧账号保留原WebView与登录，不复制或重置Cookie；新账号可选择语言和时区，使用已验证固定版本GeckoView158的分进程运行时。相同环境组合复用进程，账号以独立contextId隔离浏览器存储，标签复用原Session。

## 当前迭代

- 真实账号创建表单、旧/新账号切换和无地址栏页面已接入。
- 子进程初始化语言/时区；共享工作区采用跨进程事务锁，恢复密钥首次创建串行保护，保留原alias与旧密文。
- 原生历史/阅读位置与合成页面草稿独立加密保存，重启先只读副本，冲突不覆盖且不自动发送。
- 主进程统一线路；扩展确认代理应用后才导航，失联封锁；其他进程前台通知沿用原标签保活策略。下载流交主进程资产索引处理，避免多进程覆盖。
- 人用包和合成目标分开，测试控制Activity、测试域/信任材料不进入人用包。完整功能验收与旧数据升级都在GHA，无截图或真实ChatGPT；全部通过后才交付最终候选。
