# Android Beta.4：实时网络管理

本批沿应用内网络主线交付用户功能：网络面板实时显示准备、保存、连接与失败状态；区分已选择配置与实际已连接；保存、编辑、删除及重连后保持同一面板并更新列表。关闭面板或销毁窗口时解除订阅，使用事件通知而非定时轮询。沿用现有白灰黑沉浸布局。

候选为ChatGPT Studio Beta `3.0.0-alpha.24-beta.4` / 3000028，独立包名和固定测试签名保持，可覆盖原固定Beta而不卸载。正式版、临时测试版和个人设备不变，各应用数据不互相迁移。候选下载和实际结果将在本批Actions通过后补充；当前不宣称完成验收。

## 验证范围

- GitHub Actions构建、77项既有单元、lint、签名/16KiB/隔离检查；不本机打包。
- Android15使用已交付Beta.3原始arm64包为旧版；Android9使用上批已构建的x86 CI输入，分别精确比对已安装APK、同证书、UID和原有workspace/加密草稿/线路配置，不卸载或清数据。
- 原生控件实际添加、编辑、删除线路，观察保存/失败/重试状态及同一面板，校验关闭/重开/窗口重建/会话关闭的订阅清理。使用现有资产窗口作为原生测试宿主，不加载网页、不截图。

- NetworkRoute、网络核心、Profile身份及数据加密格式未改；复用既有路由/文件故障/保活与浏览器升级证据，不重复长后台试验。人工真实节点与正式原签名升级仍单列，main和官网下载不自动更新。
