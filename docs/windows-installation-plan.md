# Windows 安装与发布计划

目录迁移修复与更新配置已随 [2026.11.10 正式版](releases/2026.11.10.json) 发布。以下保留原候选及其 11 项目录迁移证据；后续实机验收使用新正式 EXE。

当前迭代为安装目录嵌套修复。先交 GitHub Actions 候选与合成升级报告，再决定公开发布。程序版本沿用 `2026.11.9`，候选由源码提交和 Actions 运行编号区分。

## 当前交付

- 将已注册的 `%LOCALAPPDATA%\Programs\ChatGPT Studio\ChatGPT Profiles` 迁到同级父目录 `ChatGPT Studio`。检查程序包、卸载记录和目录归属，父目录仅包含该旧程序子目录时才执行。
- 联动更新安装注册表、卸载程序、桌面 / 开始菜单快捷方式，以及合成固定快捷方式的目标、工作目录和图标。通过应用状态确认迁移后仍识别为可自动更新的 EXE 安装版。
- 备份放在安装目标外，失败时恢复原程序、注册表和快捷方式，清理本次写入的空目录，使安装可以直接重试。
- 登录与恢复数据继续保存在现有用户数据目录。合成升级比较该目录全部文件摘要，并在安装后读取原 Cookie 与 localStorage。

## 后续顺序

1. 完成本迭代候选与报告，由用户在 Windows 实机验收路径及数据。
2. 跟进 alpha.24 的“更新暂未完成”。已核对线上清单及 alpha.24 原解析函数，识别最新版本正常；用户确认使用 EXE，具体错误文字尚缺，根因未确定。
3. 完善更新下载的可见进度。Mac / Windows 2026.11.10 已正式发布，含百分比、文件大小、阶段提示及重试；Android 应用内更新下载器留待第二批。[正式记录与后续方案](update-experience-plan.md)。
4. 接入 Windows Authenticode。当前公开包与本迭代候选均未配置可信签名，仍会出现“未知发布者”。用户暂无 Windows 代码签名证书或已验证的 Artifact Signing 账号，签名服务及身份条件具备后再接入 Actions，并校验主程序、安装器与卸载器签名。
5. 继续已列入路线图的真实账号 / 文件验收、通行密钥、稳定 Apple 签名与 Touch ID、iOS 原生客户端、差量更新等工作，按各自批准范围推进。
6. Mac / Windows 共用标签栏随 [2026.11.11](https://github.com/ForceMind/ChatGPT/releases/tag/v2026.11.11) 正式发布。标签先缩小，超出的进入「更多标签」，当前标签留在标题栏。[双端 CI](https://github.com/ForceMind/ChatGPT/actions/runs/42771715875) 通过 800 像素窄窗、更新按钮占位、多标签和菜单选择验收。切换后保留原网页实例及未发送草稿；测试通过菜单项目回调完成选择，未检查操作系统菜单的视觉位置。

[2026.11.11 正式包覆盖升级验收](https://github.com/ForceMind/ChatGPT/actions/runs/42776437108) 复用了已发布且按 SHA-256 核对的安装包。Windows Server 2025 从 2026.11.10 标准目录和 2026.11.9 嵌套目录分别升级，安装目录均为 `Programs\ChatGPT Studio`。桌面、开始菜单和合成任务栏快捷方式指向 `ChatGPT Studio.exe`，卸载和更新登记正确，合成数据字节一致。macOS 15 使用 2026.11.10 随包更新助手和 2026.11.11 兼容 ZIP 在临时目录完成替换，保留旧包和合成数据。此轮未启动安装后的客户端；真实账号、系统菜单位置与真机升级仍待验收。

Android R8 正式优化批次已发布，包体及 CPU/PSS 对照结果见 [Android 优化记录](android-optimization-plan.md)。本次 Windows 候选沿用现有应用功能与保活策略。
