# ChatGPT Studio Android 测试候选：安装与数据保留

这是独立固定签名测试版，Android9及以上arm64设备。已有固定Beta的用户直接覆盖安装，不卸载、不清除数据。正式版和临时测试版使用不同包名，保持各自登录和资产，不自动迁入Beta。

本说明正在随资产/Skill 自动任务候选更新。上一批 `2026.11.06-2024` 已提供本地文件导出；下面的自动任务能力以同包验收摘要通过为准，不适用于上一批 APK。

本批起，App 显示版本和 APK 文件名统一使用上海时间 `YYYY.MM.DD-HHmm`；准确版本、内部升级序号、来源提交和证书见同包的 `android-version.json` 与 `receipt.json`。日期是本批构建时间，不是手机本地时间；历史 Beta 安装包保留原名。

旧账号继续使用原登录空间。新增账号可开启“独立语言与时区环境”，选择网页语言和时区；环境创建后固定，需要其他环境时新建空间。相同环境共用运行时，账号的Cookie与网页存储仍分开。

切换已打开标签复用原页面。程序重新启动时，保存的页面先显示本地只读副本，选择“继续页面”后连接网页；若网页已有不同草稿，明确选择保留网页或恢复本地。恢复不会自动发送，附件和模型生成任务需要手动确认。

独立环境使用完整浏览器内核，包体和内存会增加；旧账号不会因此转换内核或重新登录。可使用现有网络设置，网页上传使用系统文件选择器，下载归入所属账号资产库。

在资产库选择“交给 GPT”，核对附件、目标账号、Skill 和处理要求；跨账号发送需勾选确认。应用在目标账号创建新对话，依次准备文件、上传附件、填写完整指令并发送，顶部显示当前进度，可随时停止并从“任务”查看记录。原文件保留在来源账号；HTML/SVG/代码按文本附件处理，上传名可能追加 `.txt`，内容保持原样。

发送前取消或失败会停止处理，网页可能已形成附件或草稿，请检查目标标签。显示“结果待确认”时，先打开原对话确认，应用不会自动重发；需要重试时重新发起一个任务。关闭或重启应用后，旧任务只保留记录，恢复页面不会继续发送。

网页导出的本地图片、HTML 和文本会出现“保存网页文件”，确认后归入发起导出的原账号资产库。HTML 保存为文件，不作为 App 页面执行。取消或关闭源标签会停止本次保存；切换前台账号不会改变文件归属。若来源已过期或保存失败，请回到原网页重新导出。

安装前核对SHA256SUMS.txt。验收JSON随包附带；源码和准确验证范围见docs/android-environment-client.md。合成验收不代表真实ChatGPT、通行密钥或厂商手机已经验收。候选不自动更新正式版、官网或个人设备。

顶部直接显示对话标题，点击切换，长按或在更多中打开标签管理。右侧固定刷新；加载中显示停止。更多首排提供后退和前进，无历史时置灰；强制刷新只重新获取当前页面，不清除账号登录。导航前等待草稿加密保存，正在生成、文件任务、恢复中或保存失败时保留页面并提示。
